How it works

Export one file, move it, and resume with the full history.

  1. 01

    Export

    Pick sessions from any project. The app writes them and their subagents to one archive file.

    work.agentsessions
  2. 02

    Move the file

    Use AirDrop, a USB drive, a synced folder, or any other way you move files. The app never uploads anything.

    ~/Downloads/work.agentsessions
  3. 03

    Import and resume

    Point each project at its folder on this computer. The app writes nothing until you start, and a failed import rolls back.

    claude --resume 5c00…0000

Privacy

Treat an archive like the code it quotes.

  • Full transcripts

    An archive holds each transcript unredacted: the account email recorded in the session, system prompts, every message, and the files and command output the agent read.

  • Never credentials

    The app never includes auth tokens, API keys, or agent settings.

  • No network

    The app makes no network requests. The file goes only where you put it.

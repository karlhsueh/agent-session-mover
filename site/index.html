How it works

Export one file, move it, and resume with the full history.

  1. 01

    Export

    Pick sessions from any project. The app writes them and their subagents to one archive file.

    work.agentsessions
  2. 02

    Move the file

    Use AirDrop, a USB drive, a synced folder, or any other way you move files. The app never uploads anything. Bring your code too, with git push and pull or a copy of the project.

    ~/Downloads/work.agentsessions
  3. 03

    Import and resume

    Open the file on the other computer, confirm where each project lives, and run the resume command.

    claude --resume 5c00…0000

Import

Point each project at its folder on this computer.

Your code can live at a different path here. Import lists every project folder from the other computer and suggests the same path under your home folder.

  • Each folder shows the git branch its sessions were on, so you know what to check out.
  • Create a missing folder from the preview.
  • The app writes nothing until you start the import.
  • A failed import rolls back, and an update keeps a backup of the copy it replaces.

Resume

Pick up each session where it stopped.

After the import, every session has its resume command. Copy one, or copy them all at once.

  • Claude Code resumes with claude --resume from the mapped folder.
  • Codex resumes with codex resume.
  • An export includes the subagents each session started.
  • Cloud sessions, such as Claude Code on the web and Codex cloud tasks, already follow your account, so the app moves only local ones.

Privacy

Treat an archive like the code it quotes.

  • Full transcripts

    An archive holds each transcript unredacted: the account email recorded in the session, system prompts, every message, and the files and command output the agent read.

  • Never credentials

    The app never includes auth tokens, API keys, or agent settings.

  • Stays local

    Sessions never leave the computer except in the file you move. The app's only request checks GitHub for a new version.

The macOS app needs macOS 13 or later. The Intel build has not been tested on an Intel Mac yet, so please report what breaks. Windows and Linux builds are not code-signed yet, so SmartScreen asks you to confirm the first launch. On Linux, run chmod +x on the AppImage before you open it. Check any download against SHA256SUMS with shasum -a 256 -c SHA256SUMS --ignore-missing.
